# نظام إدارة الطلاب

نظام متكامل لإدارة الطلاب والمجموعات والحضور والدرجات والمدفوعات.

يعمل بالكامل داخل المتصفح بدون الحاجة إلى سيرفر أو قاعدة بيانات خارجية.

---

## المميزات

- **لوحة تحكم** مع إحصائيات ورسوم بيانية
- **إدارة الطلاب** (إضافة، تعديل، حذف، بحث، تفاصيل)
- **إدارة المجموعات** مع عرض الطلاب التابعين
- **نظام الحضور والغياب** مع إحصائيات
- **الدرجات والتقييمات** مع حساب تلقائي للنسبة والتقدير
- **الواجبات** مع متابعة التسليم
- **المدفوعات** مع متابعة المستحقات
- **تقارير** شاملة مع تصدير وطباعة
- **الوضع الداكن** احترافي
- **PWA** - يمكن تثبيته كتطبيق على الهاتف
- **يعمل بدون إنترنت** بعد التحميل الأول
- **تصميم متجاوب** لجميع الأجهزة
- **نسخ احتياطي** واستيراد بيانات

---

## التشغيل

### محلياً
1. افتح ملف `index.html` في المتصفح مباشرة

### على GitHub Pages
1. أنشئ مستودع جديد على GitHub
2. ارفع جميع ملفات المشروع إلى المستودع
3. اذهب إلى Settings > Pages
4. اختر分支 `main` ومجلد `/ (root)`
5. اضغط Save
6. بعد دقيقتين سيكون التطبيق متاحاً على:
   `https://USERNAME.github.io/REPOSITORY/`

---

## تثبيت التطبيق على Android

1. افتح التطبيق في متصفح Chrome
2. اضغط على القائمة (⋮) أو زر المشاركة
3. اختر "إضافة إلى الشاشة الرئيسية" أو "Add to Home Screen"
4. سيظهر التطبيق كأيقونة مستقلة على هاتفك

---

## النسخ الاحتياطي

### تصدير البيانات
1. اذهب إلى الإعدادات
2. اضغط "تصدير البيانات"
3. سيتم تحميل ملف `backup.json`

### استيراد البيانات
1. اذهب إلى الإعدادات
2. اضغط "استيراد البيانات"
3. اختر ملف `backup.json` السابق
4. تأكد الاستيراد (سيتم استبدال البيانات الحالية)

---

## حذف البيانات التجريبية

1. اذهب إلى الإعدادات
2. اضغط "حذف بيانات Demo والبدء من الصفر"
3. تأكد الحذف

## هيكل المشروع

```
student-management/
├── index.html          # الصفحة الرئيسية
├── manifest.json       # إعدادات PWA
├── sw.js               # Service Worker
├── README.md           # هذا الملف
├── css/
│   └── style.css       # ملف التصميم
├── js/
│   ├── storage.js      # إدارة التخزين المحلي
│   ├── data.js         # البيانات التجريبية
│   ├── app.js          # المتحكم الرئيسي
│   ├── dashboard.js    # لوحة التحكم
│   ├── students.js     # إدارة الطلاب
│   ├── groups.js       # إدارة المجموعات
│   ├── attendance.js   # الحضور والغياب
│   ├── grades.js       # الدرجات
│   ├── homework.js     # الواجبات
│   ├── payments.js     # المدفوعات
│   ├── reports.js      # التقارير
│   ├── notifications.js # الإشعارات
│   └── settings.js     # الإعدادات
└── assets/
    ├── logo.png         # الشعار الرئيسي
    ├── logo-small.png   # شعار صغير
    ├── favicon.png      # أيقونة المتصفح
    ├── icon-192.png     # أيقونة PWA صغيرة
    └── icon-512.png     # أيقونة PWA كبيرة
```
